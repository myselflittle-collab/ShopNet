# Almirah — 3D Wardrobe Store

A scroll-driven 3D e-commerce demo built with Three.js. Scroll to open the wardrobe and move through the hanging rail, watch shelf, shoe rack and drawer. 3D section icons open a normal 2D product panel with stock and prices.

## Run on localhost

Pick one (any of these works — no install step needed):

**Python**
```
python -m http.server 5500
```

**Node**
```
npx serve -l 5500
```

Then open http://localhost:5500 in your browser.

Needs an internet connection the first time (Three.js and Google Fonts load from CDN).

## Files
- `index.html` — the whole site (HTML, CSS, JS in one file)
